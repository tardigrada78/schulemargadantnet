# Projektkontext

Eine Webplattform mit einzelnen aber logisch verbundenen Tools für KI im Schulunterricht. Dient zur Entwicklung und Early-Access für ein kleines Publikum. 

---

# Konventionen

## Ordner
- HTML-Files liegen im Order public
- js Files für das Backend mit den Routen zur KI-API liegen im Ordner routes

---

# Arbeitsweise

- **Minimale Änderungen**: Nur anfassen, was für den Task nötig ist.
- **Kein Overengineering**: Keine abstrakten Layer hinzufügen, die noch nicht gebraucht werden.
- **Konsistenz vor Perfektion**: Bestehendem Stil folgen, auch wenn es nicht ideal ist.
- Vor einer Änderung prüfen, ob eine ähnliche Funktion bereits existiert.
- Allgemein verwenbare Funktionen in eigene Dateien schreiben und diese auch verwenden

# Repositories

- **Kein Git**: Ich verwende git selbst, uploade keine Änderungen. Beachte aber, dass es eine .gitignore gibt.
